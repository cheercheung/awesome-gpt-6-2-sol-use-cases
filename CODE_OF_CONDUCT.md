# Community conduct

Be respectful when discussing creators, models and contributions. Critique the work with evidence; do not harass people, publish private information, impersonate creators or submit discriminatory content.

Attribute original work accurately and respect removal requests. Do not spam issues with promotions or unsupported performance claims.

Report conduct problems through an issue with the minimum public context needed. Do not repeat abusive or private material. Maintainers may edit or remove inappropriate content, close discussions and restrict repeat offenders. These expectations apply to issues, pull requests and repository discussions.
